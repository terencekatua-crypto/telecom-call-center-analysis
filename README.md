# 📞 Telecom Call Center Analysis

An end-to-end data science project analyzing a simulated telecom call center dataset using Python. This project explores the factors influencing customer call duration through exploratory data analysis (EDA), visualization, and machine learning.

---

## 📂 Project Overview

This project demonstrates a typical data science workflow:

- Data Cleaning
- Exploratory Data Analysis (EDA)
- Correlation Analysis
- Feature Engineering
- Linear Regression Modeling
- Model Evaluation
- Residual Analysis

---

## 📊 Dataset

The dataset is based on a simulated telecom call center and includes variables such as:

- Call Duration
- Customer Age
- Wait Time
- Agent Experience
- Satisfaction Score
- Region
- Call Type
- Resolution Status

---

## 📈 Key Insights

- Longer wait times generally lead to longer call durations.
- More experienced agents tend to resolve calls faster.
- Customer satisfaction is negatively associated with call duration.
- Residual analysis was used to validate the assumptions of linear regression.
